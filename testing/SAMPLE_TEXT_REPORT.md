## Benefits of Text Log Format

1. **Human Readable**: Easy to read without JSON tools
2. **Searchable**: Use `grep`, `less`, or text editors
3. **Formatted**: Clear sections with headers and alignment
4. **Complete**: All test results, findings, and resources
5. **Printable**: Can be printed or included in reports

## Viewing the Report

```bash
# View entire report
cat integration_test_results.log

# View with pager
less integration_test_results.log

# Search for specific content
grep "FAIL" integration_test_results.log
grep "ERROR" integration_test_results.log

# View just the summary
head -n 50 integration_test_results.log

# View just resources detected
grep -A 100 "RESOURCES DETECTED" integration_test_results.log
```

## Files Generated

After running the integration test, you'll have:

| File | Format | Contents |
|------|--------|----------|
| `integration_test_results.log` | **Text** | Human-readable test report |
| `integration_test_results.json` | JSON | Machine-readable test results |
| `integration_test_findings.json` | JSON | Detailed findings database |
| `security-watch-test.log` | JSON | CloudTrail-style logs |
| `state-test/ACCOUNT_ID.json` | JSON | AWS resource state |

The text log provides an easy-to-read summary while the JSON files provide detailed data for programmatic analysis.
